## C4 Level 1 — System Context

```
   [Storefront]   [Seller Portal]    [Admin Portal]     [Shipper App*]
        │                │                 │                   │
        └────────────────┴─────────┬───────┴───────────────────┘
                                   │
                            ┌─────────────┐
                            │ api-gateway │   routing thuần, rate limit per-IP
                            └─────────────┘   entry point duy nhất cho mọi client
                                   │
              ┌────────────────────┼─────────────────────┐
              ▼                    ▼                     ▼
      ┌───────────────┐   ┌────────────────┐   ┌──────────────────┐
      │ web-gateway   │   │ mobile-gateway │   │ oauth2-service   │
      │ BFF — browser │   │ BFF — mobile   │   │ login form, MFA, │
      │ session cookie│   │ Bearer token,  │   │ register, OIDC   │
      │ + token       │   │ aggregation,   │   │ logout — bypass  │
      │ exchange      │   │ ACL, version   │   │ cả 2 BFF         │
      │               │   │ gating, device │   │                  │
      │               │   │ binding        │   │                  │
      └───────┬───────┘   └────────┬───────┘   └─────────┬────────┘
              │                    │                     │
              └──────────┬─────────┘                     │
                         ▼                               │
                 ┌───────────────────┐                   │
                 │ t3n-nexus Backend │◀──────────────────┘
                 │ (24 microservices)│
                 └──────────┬────────┘
                            │
          ┌─────────────────┼──────────────────┐
     [PostgreSQL]         [Kafka]            [Redis]
     [MongoDB]       [Schema Registry]  [Elasticsearch]
                          [EMQX]
```

- **api-gateway** — entry point duy nhất cho mọi client, routing thuần + rate limit per-IP, không giữ session/JWT/business logic
- **web-gateway** — BFF cho browser (3 Angular app): session cookie, token exchange, forward business API call xuống domain service
- **mobile-gateway** — BFF cho mobile (Shipper): validate JWT trực tiếp, aggregation, ACL, version gating, device binding (`adr/009-mobile-gateway.md`)
- **oauth2-service** — nhận traffic trực tiếp từ api-gateway cho `/auth/**` (login form, MFA, register, OIDC logout) — cả browser lẫn mobile đều bypass BFF ở bước này, vì đây là màn hình/flow của chính oauth2-service, không phải business API
- `*` Shipper chưa có mobile app — đang được giả lập bởi `simulator-service`

## Cross-Cutting Concerns

| Concern              | Approach                                                                |
|----------------------|-------------------------------------------------------------------------|
| **Observability**    | OpenTelemetry (traces + metrics), structured logging với traceId/spanId |
| **Resilience**       | Resilience4j — Circuit Breaker, Retry, Bulkhead                         |
| **Security**         | ABAC in-process tại mỗi service — chi tiết: `security-architecture.md`  |
| **Idempotency**      | Redis-based idempotency key — bắt buộc cho payment + order              |
| **Schema Evolution** | Confluent Schema Registry + Avro — backward compatible                  |
